# Security

If you find a security problem in Zynko (for example, in the local network features such as typing from the phone or the Home Assistant API), please **do not open a public issue**.

Report it privately through GitHub: *Security › Report a vulnerability* in this repository. Include the Zynko version, what you found and, if possible, how to reproduce it.

We will acknowledge the report and keep you informed while it is fixed.
