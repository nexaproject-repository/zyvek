# Zynko user guide

The guide will be completed as features are released.

1. **Install Zynko** — requirements, download and installation.
2. **First start** — sign in to Plex, choose libraries and categories, create the main profile.
3. **Home and menu** — sections, posters and landscape cards, customising the sidebar.
4. **Watching** — the player, audio and subtitles, versions, playback info.
5. **Profiles** — adding profiles, PIN, avatars, Plex Home.
6. **Search and watchlist** — search, people, notifications.
7. **Settings** — *My profile* and *This house*.
8. **Audio and video** — HDR, passthrough and the audio configuration test.
9. **Philips Hue Sync** — connecting the bridge and choosing an entertainment area.
10. **Remote control and keyboard** — keys and typing from the phone.
11. **Troubleshooting** — playback, network and Plex remote access (Plex Pass / Remote Watch Pass).
